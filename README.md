# LivingAtlas

LivingAtlas is a front-end web application built as a capstone project at Washington State University. The project focuses on creating an interactive map-based experience for exploring and visualizing geographic information in a user-friendly interface.

## Project Description

LivingAtlas is designed to help users interact with location-based data through a modern React application. It includes map-driven features, route navigation, and UI components that support a clean browsing experience for exploring places and related data.

This project was created to demonstrate full-stack front-end development skills, using React for the user interface and supporting libraries for mapping, routing, and data interactions.

## Requirements

Before running the project, make sure the following are installed on your machine:

- Node.js 18 or later
- npm 9 or later
- A modern web browser such as Chrome, Edge, or Firefox
- Internet access for external map and API dependencies

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/falvarezpenate/living-atlas.git
   cd living-atlas
   ```

2. Navigate to the client application folder:
   ```bash
   cd client
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

## Running the App

From the `client` directory, start the development server:

```bash
npm start
```

This will launch the React app in development mode. You can then open the local URL shown in the terminal (usually `http://localhost:3000`) in your browser.

## Project Structure

- `client/` - React front-end application
- `package.json` - Root project dependencies

## Notes

This repository contains the front-end code for the project. The app is built with React and uses libraries such as Mapbox, React Router, and Bootstrap to support the interactive experience.
