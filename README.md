# LivingAtlas

LivingAtlas is a front-end web application built as a capstone project at Washington State University. The project focuses on creating an interactive map-based experience for exploring and visualizing geographic information in a user-friendly interface.

## Project Description

LivingAtlas is designed to help users interact with location-based data through a modern React application. It includes map-driven features, route navigation, and UI components that support a clean browsing experience for exploring places and related data.

This project was created to demonstrate full-stack front-end development skills, using modern web technologies and libraries to build a scalable, maintainable application.

## Requirements

Before running the project, make sure the following are installed on your machine:

- Node.js 18 or later
- npm 9 or later
- A modern web browser such as Chrome, Edge, or Firefox
- Internet access for external map and API dependencies

## Tech Stack

### Frontend Framework
- **React 18** - A JavaScript library for building user interfaces with component-based architecture
- **React Router DOM** - Client-side routing for seamless navigation between pages

### Mapping & Geolocation
- **Mapbox GL** - Powerful mapping library for rendering interactive, customizable maps
- **Mapbox GL Draw** - Tool for drawing and editing geographic features on the map
- **Mapbox GL Geocoder** - Geocoding and reverse geocoding for address lookup and location search

### UI Components & Styling
- **React Bootstrap** - Bootstrap components built as React components for consistent UI design
- **Bootstrap** - CSS framework for responsive design and pre-built components
- **CSS** - Custom styling for component-specific designs and animations

### HTTP Client
- **Axios** - Promise-based HTTP client for making API requests to backend services

### Testing & Development
- **React Scripts** - Build and test configuration for Create React App
- **Mocha** - JavaScript test framework for unit testing
- **Chai** - Assertion library for test writing
- **Jest & React Testing Library** - Testing utilities for React components
- **Selenium WebDriver** - Browser automation for end-to-end testing

### Build Tools
- **Create React App** - Zero-configuration setup for React development

## Project Structure

- `client/` - React front-end application with all components and pages
- `public/` - Static assets and HTML entry point
- `src/` - React components, pages, and application logic
- `package.json` - Project dependencies and scripts

## Notes

This repository contains the front-end code for the project. The application is built with modern React practices and integrates with Mapbox for interactive mapping capabilities. The tech stack emphasizes component-based architecture, responsive design, and robust testing practices.
